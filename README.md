# Voice Scribe для Windows

Локальная диктовка на русском через GigaAM v3 (Сбер). Поставьте курсор в текстовое
поле, нажмите **Ctrl+Space** (или своё сочетание), скажите фразу и завершите запись —
текст распознается на компьютере и вставится в исходное окно через буфер обмена.

Есть словарь замен, голосовые знаки препинания, выбор любой клавиши для записи,
Enter после вставки и автообновление.

С версии 0.4.0 Voice Scribe — это бывшая Voice Scribe Lite. Прежняя полная версия
с Whisper, расшифровкой файлов, определением ораторов, вычиткой через API и историей
больше не развивается; её код остался в ветке `full-app` и в тегах до v0.3.5.

## Запуск

Скачайте **Voice-Scribe-Setup-…-x64.exe** из
[последнего релиза](https://github.com/mrrepac/voice-scribe-desktop/releases/latest).
Модель GigaAM v3 входит в установщик (он весит около 280 МБ), поэтому интернет
для распознавания не нужен ни при первом запуске, ни потом.

Из исходников: `npm install`, затем **Start-Voice-Scribe.cmd** или `npm start`.
При запуске из исходников модель скачивается при первой диктовке.

### Переход со старых версий

- **Полная версия (до 0.3.5)** обновляется сама, на том же месте и с теми же
  настройками. При первом запуске новая версия удаляет из `%APPDATA%\Voice Scribe`
  скачанные модели и временное аудио. История и зашифрованный ключ API остаются
  на диске, но больше не используются; их можно удалить вручную.
- **Voice Scribe Lite** не обновляется в Voice Scribe: это отдельная программа.
  Установите Voice Scribe — при первом запуске он один раз перенесёт настройки Lite
  и удалит скачанную ею модель. Затем удалите Voice Scribe Lite через «Параметры →
  Приложения». Не запускайте обе программы одновременно: они перехватывают одни
  и те же клавиши.

## Горячие клавиши

Сочетания ниже даны для варианта по умолчанию, Ctrl+Space. Как выбрать другое, описано
после таблицы.

| Сочетание | Действие |
|---|---|
| Короткое Ctrl+Space | Начать запись; следующее нажатие — закончить и вставить текст |
| Удерживать Ctrl+Space | Записывать до отпускания клавиш |
| Enter во время записи | Завершить, вставить текст и нажать Enter (можно отключить) |
| Escape | Отменить текущую запись или распознавание |
| Ctrl+Alt+V | Вставить последний текст в текущее окно |

### Своё сочетание для диктовки

Сочетание выбирается в настройках. Есть четыре готовых варианта: Ctrl+Space
(по умолчанию), Ctrl+Alt+Space, левые Win+Alt и Insert. С Insert сочетания
Shift+Insert и Ctrl+Insert продолжают работать как вставка и копирование.

Пункт **«Своя клавиша…»** в конце того же списка позволяет выбрать любую другую
клавишу или сочетание. Выберите его и нажмите нужные клавиши; Esc отменяет выбор.
Назначенное сочетание появится в списке рядом с готовыми. Подойдут:

- одиночные F1–F24, CapsLock, Pause, ScrollLock, PrintScreen, медиаклавиши;
- любая клавиша вместе с Ctrl, Alt или Win (можно добавить и Shift), например Ctrl+Shift+D
  или Win+K;
- одиночные клавиши из первого пункта с Shift, например Shift+F9.

Не принимаются буквы, цифры, пробел, Enter и стрелки без Ctrl, Alt или Win (в том числе
с одним Shift), иначе они перестанут печатать. Esc и Ctrl+Alt+V заняты, одиночный
модификатор вроде правого Ctrl назначить нельзя. Удержание и подсказки в интерфейсе
работают с выбранным сочетанием так же, как с Ctrl+Space.

Выбранное сочетание перехватывается во всех программах. Если в нём есть Win или Alt
без Ctrl, Voice Scribe не даёт их отпусканию открыть «Пуск» или меню приложения.

### Enter после вставки

В настройках можно перечислить программы, в которых после вставки всегда нажимается Enter.

## Выпуск новой версии

1. `npm version patch` (или `minor`) повышает версию, создаёт коммит и тег.
2. `git push origin main --follow-tags` запускает Windows release: проверка типов,
   тесты, сборка Setup и публикация в GitHub Releases.
   Перед сборкой `npm run fetch-model` кладёт модель в `models/` (в git её нет)
   и сверяет SHA-256; в CI она кэшируется по закреплённой версии.
