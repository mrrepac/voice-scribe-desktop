      Голосовые знаки препинания

      Говорите «запятая», «точка», «новая строка», «новый абзац».

      Возвращать прежнее содержимое буфера

      После автовставки в буфер обмена вернётся то, что было скопировано до диктовки. Если вставка не удалась, текст останется в буфере. Медленные приложения, например удалённый рабочий стол, могут не успеть прочитать текст — тогда вставьте его через Ctrl + Alt + V.

      Звуковые сигналы

      Короткий звук в начале записи и после готового результата.

      Вычитка через API

      Подключить языковую модель

      По Ctrl + Shift + Space текст отправляется на указанный сервер для вычитки. Аудио не отправляется. Возможна оплата по тарифам провайдера.

      «Получить модели» проверяет каталог сервиса. «Проверить модель» отправляет короткий тестовый текст и может тарифицироваться.
