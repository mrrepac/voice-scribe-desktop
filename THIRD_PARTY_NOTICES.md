The original Voice Scribe recognition, transcript cleanup, audio segmentation,
and text-processing code was reused or adapted for this standalone application.
The original MIT notice is retained in the project's `LICENSE` file. Application
integration and global Windows insertion are implemented separately from Obsidian.

Transformers.js and ONNX Runtime are used for local inference. Their JavaScript
and WebAssembly runtime files are bundled with the application. License comments
generated by the JavaScript bundler must also be preserved when redistributing
compiled files.

Whisper model weights and configuration files are downloaded separately from
the `onnx-community` repositories on Hugging Face. They are not part of the
application executable. Their repository/model-card license information applies
to redistribution of those model files.

Development tools and their dependencies retain their own notices in
`node_modules`. The locked versions used for this build are recorded in
`package-lock.json`.

licenses/onnxruntime-LICENSE.txt). The pyannote segmentation 3.0 ONNX model
